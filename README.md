# Afreen Shaik | Interactive Portfolio

A personal portfolio website for **Afreen Shaik**, an MCA student interested in software development and AI, built with plain HTML, CSS and JavaScript.

**Live site:** https://afreenshaik-07.github.io/Portfolio/

## What is inside

Each section is its own page. Use the **Next** and **Back** buttons, the dots, the arrow keys, or swipe on a phone.

- Home with photo, name and contact links (phone, email, GitHub, LinkedIn)
- About me
- Education
- Technical skills, with icons
- Internship
- Projects
- Certifications
- Interests
- Contact, with a resume download button

## Features

- One page per section with smooth page transitions
- Animated name, typing effect, count-up numbers and progress ring
- Flip cards for projects
- Responsive layout for computers and phones
- Dark theme with lilac and peach accents

## Built with

- HTML5
- CSS3
- JavaScript (no frameworks or libraries)

## Run it on your computer

1. Download `index.html` and `Afreen_Shaik_Resume.pdf` into the same folder.
2. Double-click `index.html` to open it in a browser.
